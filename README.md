智能食谱推荐助手
项目概述：智能食谱推荐助手是一款旨在帮助用户轻松选择合适食谱，并提供食物营养价值信息的应用程序。无论你是烹饪新手还是美食爱好者，都能通过本助手快速找到符合口味和营养需求的美食制作方法，同时了解食材背后的营养价值，做出更健康的饮食选择。

环境要求：
操作系统：支持 Windows、macOS、Linux。
编程语言及版本：Python 3.8 及以上。

依赖库：
Flask：搭建后端 Web 服务，创建应用、定义路由、处理请求响应
request（flask 内置）：处理客户端 HTTP 请求，获取请求参数、头信息等
jsonify（flask 内置）：将 Python 数据转 JSON 响应，用于构建 API 返回
CORS（flask_cors）：配置跨域资源共享，解决前后端跨域访问限制
requests：发送 HTTP 请求，从外部获取数据（如食材营养信息 ）
os：与操作系统交互，获取环境变量、操作文件 / 目录
json：处理 JSON 数据，实现字符串与 Python 数据结构互转
re：用正则表达式做字符串匹配、提取、替换等文本处理
glob：按通配符模式查找文件路径，批量处理文件（如食谱数据文件 ）
load_dotenv（dotenv）：加载 .env 文件中的环境变量，管理配置

安装步骤：
1、克隆项目：git clone git@github.com:xiangsurener/aha-xiximitol.git
2、上网搜索“node.js”，并下载对应版本
3、找到 backend 文件夹，用python 安装所需要的库，并运行 app.py 程序。
4、返回上一级文件夹，找到 frontend 文件夹，双击run_dev.bat 文件。
5、等待一会弹出命令窗口，显示一段网址，复制网址到浏览器并加载，即可开启体验。

功能模块
窗口一：食谱推荐
个性化推荐：根据用户的口味偏好（如微辣、清淡等）、主要食材（如鸡肉、土豆等）以及有无忌口等，为用户精准推荐适合的食谱。

窗口二：营养价值和热量查询
食物营养价值：输入某种食物，即可获取其热量、蛋白质、脂肪、碳水化合物、维生素、矿物质等详细的营养价值信息。
